# LIYAN — Charte de marque

Extraite des planches fournies dans `assets/marque/`.

## Identité

| | |
|---|---|
| Nom | **LIYAN** — ليان |
| Signature | لحظات صغيرة، معنى كبير — *Little moments, big meaning* |
| Traduction | Petits moments, grand sens |
| Site référencé | `www.liyan.tn` |
| Réseaux | `@liyan.baby` |

Le logotype associe le mot arabe ليان, un cœur en contrepoint, et la translittération
latine LIYAN en capitales espacées. Trois déclinaisons existent : principale (empilée),
horizontale et verticale. Un monogramme et une icône fleur complètent le système.

## Couleurs

| Nom | Hex | Pantone |
|---|---|---|
| Pearly Mint | `#BFCFC0` | 621 C |
| Pale Raspberry | `#E7A8B4` | 691 C |
| Cream | `#F7F3EC` | 7499 C |
| Soft Taupe | `#CDC4B7` | Warm Gray 2 C |
| Warm Gray | `#BA867C` | Warm Gray 6 C |

Le vert porte le logotype et les aplats, le rose sert d'accent (cœur, détails), le crème
est le fond dominant. Les deux gris structurent les textes secondaires.

## Typographies

- **Principale** — Lato Bold
- **Secondaire** — Noto Sans

## Finitions validées

Impression standard, embossage à sec, marquage à chaud doré, usage en réserve sur fond
coloré. La charte prévoit un espace de protection autour du logo égal à la hauteur du cœur.

## Applications documentées

Sac cadeau, boîte à ouverture aimantée avec calage intérieur, ruban satin personnalisé,
pochette en tissu réutilisable, carte de remerciement, guide d'entretien, stickers,
sceau rond, carte de visite.
